# Security policy

Travel Lockdown changes local security and network controls, so reports that could affect recovery, privilege boundaries, secret handling, or false status claims should be handled privately.

## Reporting a vulnerability

Use this repository's **Security** tab and choose **Report a vulnerability** to open a private GitHub security advisory. Please do not include exploit details, private network names, recovery baselines, or other sensitive host data in a public issue.

Include the affected commit, macOS version, expected result, observed result, and a minimal reproduction that does not contain credentials. You should receive an initial acknowledgement within seven days.

## Supported versions

Security fixes are made on the current `main` branch. This project is currently distributed as source. Locally built app bundles are ad-hoc signed; there is no notarized binary release yet.
